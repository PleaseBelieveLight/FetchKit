# FetchKit 项目结构速览

[文档中心](../README.md) · [核心设计与约束](../design/核心设计与约束.md)

供首次阅读仓库或准备修改代码的开发者快速定位。路径均相对于仓库根目录，同用途的包名和资源子目录合并说明。

## 先看下载链路

Android App 通过 Kotlin API 和 JNI 提交任务，主机程序通过 C/C++ API 提交任务。两条入口共用 C++
核心，由它负责调度、重试、续传和文件落盘。Android 通过 OkHttp 读取网络数据并分块交给 C++，主机使用
libcurl 后端。

## 核心与公开接口

| 目录                | 职责与用途                                                                   |
|---------------------|------------------------------------------------------------------------------|
| `include/fetchkit/` | C ABI、C++ 封装和版本声明。查主机接入方式、参数和生命周期约定从这里开始。    |
| `src/core/`         | C ABI 实现、引擎、下载会话、订阅、重试和诊断。修改下载策略或任务状态看这里。 |
| `src/storage/`      | 暂存文件、断点记录、摘要校验、发布和缓存空间管理。排查落盘或恢复问题看这里。 |
| `src/transport/`    | HTTP 后端接口及主机 libcurl 实现。修改传输边界或主机网络行为看这里。         |

## Android 模块

下表路径相对于 `platform/android/`。各模块的 `java/com/luofelix/fetchkit/…` 是 Kotlin 或 Java 的包路径。

| 目录                                                             | 职责与用途                                                                                                                          |
|------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| `sdk/src/main/java/` · `sdk/src/main/cpp/`                       | 前者提供 Kotlin API 和 OkHttp 适配，后者实现 JNI 桥接并接入共享 C++ 核心。                                                          |
| `sdk/src/test/` · `sdk/src/probe*/`                              | 前者是 SDK 单测，后者包含探针桥接和实验网络后端，用于对照验证。                                                                     |
| `coroutines/src/main/` · `coroutines/src/test/`                  | 可选协程适配及其单测。查挂起调用和协程事件接入看这里。                                                                              |
| `sample/src/main/`                                               | Compose 演示界面、系统调度接入和 App 配置。其下 `ui/theme/` 管理主题，`res/` 管理图标、文案和 XML 配置，`keepRules/` 存放保留规则。 |
| `sample/src/debug/` · `sample/src/{test,androidTest,probeTest}/` | Debug 专用网络配置和测试证书，以及样例单测、设备测试和探针测试。                                                                    |
| `sample/branding/` · `sample/signing/`                           | 演示 App 的品牌源素材和公开演示签名材料。                                                                                           |

## 示例、测试与构建

| 目录                                                    | 职责与用途                                                                                                                                          |
|---------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| `examples/cli/`                                         | 主机命令行示例，用于快速体验下载和查看任务状态。                                                                                                    |
| `examples/consumer/` · `examples/android-consumer/`     | 独立 C/C++ 与 Android 消费者工程，用于验证 SDK 产物的外部接入。Android 的 `src/main/` 放通用入口，`src/future/` 与 `src/coroutines/` 放各接入变体。 |
| `tests/unit/` · `tests/contract/`                       | 验证核心与公开 API，以及传输后端契约。                                                                                                              |
| `tests/protocol/` · `tests/recovery/`                   | 验证 HTTP 下载与续传行为，以及中断恢复和大文件场景。                                                                                                |
| `tests/server/` · `tests/fixtures/`                     | 可控 HTTP 服务及测试数据，包含存储记录样本和 `m4-tls/` 测试证书，用于复现边界条件。                                                                 |
| `tests/ci/` · `tests/packaging/`                        | 验证 CI 脚本、制品内容、发布保护和样例 Release 启动。                                                                                               |
| `tools/ci/` · `tools/release/`                          | 前者运行主机及设备验收并采集证据，后者准备发布预览、预发布和检查发布门槛。                                                                          |
| `tools/size/`                                           | 测量 SDK 接入增量。`android-host/` 是测量宿主，`src/main/` 提供公共入口，`src/modes/` 存放不同测量模式。                                            |
| `cmake/` · `gradle/wrapper/`                            | CMake 安装配置模板和 libcurl 固定依赖配置，以及 Gradle Wrapper。Gradle 版本目录文件位于 `gradle/`。                                                 |
| `.github/workflows/` · `.github/actions/setup-android/` | GitHub Actions 的构建、验证和预发布流程，以及可复用的 Android 环境准备步骤。                                                                        |
| `third_party/picosha2/` · `third_party/licenses/`       | 随仓库维护的摘要实现及第三方许可材料，用于追溯依赖和打包合规。                                                                                      |

根目录的 `CMakeLists.txt` 和 `settings.gradle.kts` 分别是主机构建和 Android 工程入口，`VERSION`
提供项目版本。
