首轮 Native 接入失败源于示例写死 `0.1.0`。示例现在根据传入版本精确匹配数字部分，并检查完整预发布后缀。

首轮 API 35 矩阵因 ADB 读取设备日志超时中止。驱动现在有限重试，仍检查完整测试数量和本轮报告标识。
首轮日志保留在 `api35.log`。外部宿主先在模拟器关闭时构建，再用相同 APK 和 AAR 的哈希做设备验证。

## 仍待验收

本机可用证据覆盖 Windows 和 Android x86_64 模拟器。发布仍缺少 Linux 协议与实际大文件、独立 sanitizer 和真实 ENOSPC、
API 24/37 与物理 arm64 矩阵、物理 Android 实际大文件、物理重启和第三方许可审核。
A3 的实际断网切网、非计费约束和通知生命周期，A4 的真实 SAF 授权故障和超过 4 GiB 的文件导出仍待专项验收。
